# Inbox

Drop raw material here for a specific review. Group related files together, such as slide photos in `velocity-slides/`.

When asked to review slides, read the relevant Notion export first if available. Extract additions or conflicts that could change what we say, show, submit, or rehearse. Quote judging criteria, deadlines, and pitch or demo rules exactly where legible. Include the source filename and flag blurry text or disagreements. Save the findings in [artifacts](../artifacts/README.md).
