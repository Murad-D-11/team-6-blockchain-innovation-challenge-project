# Solstice

Solstice helps migrant workers understand who should cover their pre-departure bills. Employers and lenders can pay providers directly, and workers can repay loans through a share of the money they send home through Solstice.

The prototype uses fictional participants and a demo asset on Stellar Testnet. Start with the [app guide](app/README.md) for a wallet-free local walkthrough, the expected demo results, and the Testnet contract configuration.

- [App](app/) — Next.js screens for workers, families, providers, funders, and employers
- [Soroban contract](contracts/laya/src/lib.rs) — provider settlement, remittance splitting, and loan balances

Older code and some screens use the project's earlier name, Laya.
